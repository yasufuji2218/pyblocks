# PyBlocks

Python学習用Scratch風アプリのMVP。Node.js 20以降とブラウザーで利用できます。

## 起動

Windowsでは `start.cmd` をダブルクリックすると起動できます。起動後、ブラウザーで http://127.0.0.1:4173 を開き、利用中は起動したウィンドウを開いたままにしてください。PATH上のNode.js、標準インストール先、このPCのCodex付属Node.jsの順に検索します。

このフォルダーで `node server.mjs` を実行し、http://127.0.0.1:4173 を開きます。依存パッケージのインストールは不要です。停止はターミナルで Ctrl+C。

## 使い方

1. 左のカテゴリを選び、ブロックをワークスペースへドラッグします。
2. ブロックを上下につなぎ、値のブロックを入力欄にはめ込みます。
3. 右のPythonコードを確認し「実行する」を押します。
4. 下部に出力が表示されます。「停止」で実行中・読み込み中の処理を中止できます。

変数は「変数」カテゴリから作成できます。ifブロックの設定からelif・elseを追加できます。基礎・ライブラリのサンプル、自動保存、元に戻す、Pythonファイルのダウンロードに対応しています。

## 実装範囲

- Blocklyによるドラッグ＆ドロップ、数値、文字列、print、変数代入、四則演算、比較、if / else、for
- 編集時のPython生成、コード表示、実Python実行、実行結果と初心者向けエラー説明
- ブラウザーのlocalStorageへの自動保存（同じブラウザー・同じURLで復元）

練習問題・採点とゆっくり実行に対応しています。手動で1行ずつ進めるステップ実行と直接コード編集は未実装です。名前は仮称です。

## 練習問題

画面上部で問題を選び「取り組む」を押します。組み立て・穴埋め・修正・自由制作の4形式、Level 1〜5の初期12問を収録しています。「採点する」で出力・必須ブロック・変数の状態などを判定し、部分点と完全正解を表示します。

「次のヒント」は4段階です。「採点を中止」で停止でき、「自由編集へ戻る」で練習前のブロックを復元できます。練習中は自由編集の自動保存を上書きしません。練習の回答・試行回数は再読み込みでリセットされます。

問題データの形式・採点仕様・残課題は[設計書](docs/exercises.md)、確認済みのテストは[検証記録](docs/validation.md)を参照してください。

## 実行と制限

PythonはPyodideのWebAssemblyランタイムをWeb Worker内で実行します。サーバーは静的ファイルの配信のみで、ユーザーのPythonをホストOS上では実行しません。ホストのファイルシステムはマウントしていません。実行ごとにWorkerを作り直すため、変数は引き継がれません。

読み込み制限180秒、実行制限10秒、出力上限1000行（1行4000文字）。停止と時間制限ではWorkerを終了します。ブラウザーのメモリー消費を厳密に制限する仕組みではありません。Pyodide自体にはブラウザー内の仮想ファイルシステムや通信機能があり、任意コード向けの強固なセキュリティサンドボックスとして扱わないでください。初版はブロック生成コードのみ実行します。

Blockly 12.3.1、Pyodide 0.27.7、フォントをCDNから取得するためインターネット接続が必要です。初回実行はPythonのダウンロードに時間がかかります。オフライン利用は未対応です。保存内容はこのブラウザー内だけに残り、ブラウザーのデータ削除で消えます。

## 検証

`node --test test/*.test.js` で採点・実行制御・エラー説明等のテスト271件を実行できます。構文検査は `node --check public/app.js` と `node --check public/worker.js`。

ブラウザーで4つのサンプルの生成コードと出力（「こんにちは、Python！」、15、「大きい」、1〜10）、再読み込み後のブロック復元を確認済みです。停止・時間制限・出力制限の境界動作、ドラッグ操作の網羅的な検証、モバイル操作は未検証です。

公式資料: [Blocklyのコード生成](https://docs.blockly.com/guides/app-integration/run-code/)、[PyodideのWorker実行](https://pyodide.org/en/stable/usage/webworker.html)。

## 追加ブロック

繰り返しカテゴリにwhile / until、変数を増やす、リストの各要素を繰り返す、break / continueを追加しました。
リストカテゴリではリストの作成・長さ・要素の取得・変更・挿入・削除・検索を利用できます。要素の番号はBlocklyの標準に合わせて1から数え、Python生成時に0始まりへ変換します。
関数カテゴリには戻り値あり・なしの定義と条件付きreturnがあります。定義すると呼び出しブロックが追加されます。歯車から引数を追加できます。
サンプル「whileで1から5まで」「リストの中身を表示」「引数と戻り値を使う」を追加しました。


## ゆっくり実行

実行ボタン横の「ゆっくり実行」をオンにすると、実際に通った処理ブロックを0.7秒ずつ強調表示します。繰り返しや関数内の処理も対象です。値だけのブロックは個別には点灯しません。表示・保存用Pythonには学習用の待機処理を含めません。通常実行は10秒、ゆっくり実行は120秒で停止します。停止ボタンで途中終了できます。


ゆっくり実行では右側のPythonコードに行番号を表示し、対応する実行行を黄色で強調します。表示範囲外の実行行へ自動スクロールし、終了・停止時は強調を解除します。


## 外部入力

「入力・変換」カテゴリの入力ブロックはPythonのinput()を生成し、実行結果欄のフォームで文字列を受け取ります。送信ボタンまたはEnterで再開します。整数・小数・文字列への変換ブロックも利用できます。サンプル「入力した数字を表示」を追加しています。
入力待ちは実行時間に含みません。停止ボタンで入力待ちを中止できます。入力上限は4096文字です。SharedArrayBufferに対応した最近のブラウザーとlocalhostが必要です。サーバーの分離ヘッダーを追加したため、更新後はサーバーを再起動してください。


## 標準ライブラリとPython実践コース

標準ライブラリ入門カテゴリにrandom・math・datetime・time・statistics、Python実践コースカテゴリにNumPy・pandas・Matplotlibを追加しました。各ブロックからimportを自動生成します。実践ライブラリはPyodideが必要なものをダウンロードします（初回は最大180秒）。インストール操作は不要です。
CSVはUTF-8・拡張子.csv・2MB以下、1ファイルをブラウザー内で保持し、実行時にはdata.csvとして読み込みます。再読み込みするとサンプルCSVに戻ります。読み込んだファイルをサーバーへ送信しません。pandasの表の確認には表示ブロックを使用します。
グラフは「グラフを表示」ブロックで実行結果欄へPNG表示します。1実行10枚までです。標準フォントに日本語グリフがないため、グラフのタイトル等は英数字を推奨します。
実践サンプルはday,value列のCSVを対象にしています。他の列を使う場合はブロックの列名も変更してください。NumPyの要素・pandasの行番号は0始まりです。time.sleepも実行時間制限に含みます。
コースはブロックカテゴリとサンプルとして提供しています。練習問題は基礎・mathを含む初期12問です。実践ライブラリの課題とコース修了判定は今後の拡張対象です。
